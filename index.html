🎄 Mode d'emploi

  1. Créer un profil avec + : prénom, âge et photo/avatar (facultatifs). Le crayon ✏️ permet de modifier ou supprimer un profil.
  2. Dans la liste, + ajoute une photo de jouet (appareil photo ou galerie), puis tu peux indiquer le nom du jouet et le magasin.
  3. +++ ajoute une série de photos : le magasin saisi est pré-rempli pour les photos suivantes, il suffit d'indiquer le nom de chaque jouet.
  4. Un appui court sur un jouet ouvre la modification / suppression.
  5. Un appui long de 3 secondes sur une photo active le mode sélection 🔒 : les parents cochent uniquement les jouets à partager, puis Valider exporte la sélection en image. Les petits n'y voient que du feu !
  6. « Envoyer la lettre au Père Noël » lance l'animation et enregistre la date d'envoi. La liste reste modifiable.
  7. Partager la liste exporte tout en image (format A4) via WhatsApp, SMS… PDF est une solution de secours.
  8. Le curseur de sagesse est là pour demander à l'enfant où il pense se situer 😇.
  9. 🗑 vide la liste (après Noël par exemple), avec confirmation.

Toutes les données restent sur ton téléphone. Fonctionne hors ligne.
